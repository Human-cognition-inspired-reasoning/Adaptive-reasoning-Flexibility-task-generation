# water-pipes

3×3 격자의 파이프 타일을 눌러 돌려, 물이 정해진 색 칸에 닿게 하는 태스크입니다. 한 문제는 5라운드이고, 라운드마다
**규칙 · 목표**가 바뀌며 **조건(격자)은 제출마다** 바뀝니다. 규칙과 목표는 알려 주지 않으며, 모델은 제출할 때마다 받는
피드백으로 찾아야 합니다. 라운드가 바뀐 뒤에도 직전 규칙을 따르는 오답(지속적 오류)이 얼마나 나오는지로 적응을 잽니다.

## 태스크 구성

| 구성 | 내용 |
|---|---|
| 조건 | 3×3 격자: 물 1칸, 색 칸 3개(빨강 · 노랑 · 파랑), 돌 0~1칸, 나머지 파이프. 배치는 라운드마다 새로 뽑고, 라운드 안에서는 파이프의 처음 방향만 제출마다 섞음. 질문마다 글로 보여 줌 |
| 규칙 | 같은 타일을 이어 누르는 횟수: ×1 · ×2 · ×3+ 가운데 하나. 매 라운드 바뀌고 직전과 겹치지 않음. 숨김 |
| 목표 | 물이 닿아야 할 색 칸 조합(나머지 색 칸은 말라 있어야 함). R1은 세 색 모두, 그 뒤 매 라운드 바뀜. 숨김 |
| 피드백 | 물이 닿은 색, 틀린 타일 번호, 정답 여부. 틀린 이유는 알려 주지 않음 |

- 타일을 한 번 누르면 시계 방향으로 90° 돕니다. 모델은 누를 타일 번호의 순서를 한 번에 제출합니다.
  피드백 예: `Water reached red. Wrong at tiles 3 6. Not the answer.`
- 라운드마다 T=10번 안에 연속 k=2번 맞혀야 다음 라운드로 넘어가고, 못 넘어가면 그 문제는 거기서 끝납니다.
- 지속적 오류는 직전 라운드의 규칙을 지킨 오답이며, 그 제출의 격자로 판단합니다. 라운드 PER은 지속적 오류 수 ÷
  채점된 제출 수(R2~R5), 문제 MPE는 그 문제의 PER 평균, 전체 MPE는 문제 MPE의 평균입니다.
- 처음 방향이 달라 타일마다 누를 횟수는 매번 다시 세야 하지만, 목표를 만드는 마지막 방향은 라운드 동안 같아 틀린
  타일 번호는 같은 칸을 가리킵니다.
- 생성 보장(판마다, `bench/verify.py`)
  - 정답이 있고, 아무것도 안 누르면 틀림
  - 직전 격자의 정답은 이 격자에서 모두 틀림(라운드 안에서는 목표를 만드는 회전 배치가 직전 격자와 겹치지 않게 섞음)
  - 라운드가 바뀐 격자: 지금 목표를 직전 규칙으로도 만들 수 있고, 직전 목표도 만들 수 있음
  - 라운드가 바뀐 격자: 직전 목표를 가장 적게 돌리는 배치로 타일마다 이어 누르면 직전 규칙을 지킴

## 폴더

| 경로 | 내용 |
|---|---|
| `bench/engine.py` | 격자, 회전, 물 흐름, 판정 |
| `bench/generate.py` | 문제 생성 |
| `bench/verify.py` | 생성 보장 검사(생성기의 판단을 쓰지 않고 엔진으로 다시 셈) |
| `bench/prompt.py` | 모델에게 주는 글 |
| `bench/runner.py` | 모델 실행 |
| `bench/drivers.py` | Anthropic · OpenAI API 연결 |
| `bench/score.py` | 실행 기록 채점(MPE, 95% 구간, 우연 기준) |
| `bench/selftest.py` | 판정과 글 자체 검사 |
| `episodes/episodes.json` | 문제 300개(Q001~Q300), 라운드마다 격자 10장 |

## 실행 순서

```bash
cd benchmark/water-pipes
pip install -r requirements.txt               # 문제 생성에 numpy, 모델 실행에 API 패키지
python3 bench/generate.py 300 20261117 8 4000 # 문제 300개 (씨앗 20261117, 병렬 8, 배치 묶음 4000) → episodes/episodes.json
python3 bench/verify.py                       # 생성 보장 검사
python3 bench/selftest.py                     # 판정과 글 자체 검사

export ANTHROPIC_API_KEY=... OPENAI_API_KEY=...
python3 bench/runner.py gpt-6.1-sol --episodes 100 --jobs 10   # → runs/<시각>/
python3 bench/score.py runs/<시각>              # 이어 돌린 실행 여럿은 --merge runs/<시각1> runs/<시각2>
```

- 생성은 8코어에서 6분쯤, 검사는 4분쯤 걸립니다.
- 판이 라운드마다 10장이라 `-T`는 10을 넘을 수 없습니다.
- 검증과 채점은 파이썬 표준 라이브러리만 씁니다.
- 실행 기록(`runs/`)은 저장소에 올리지 않습니다(`.gitignore`).

## 결과 (v1.1, 2026-11-17~18 실행, Q001~Q100)

| Model | N | MPE, % | Mean error, % | API time, min | Cost, USD |
|---|---|---|---|---|---|
| GPT-6.1 Sol | 70/100 | 42.96 | 75.52 | 312.05 | 7.3328 |

- N은 MPE에 들어간 문제(R1을 통과한 문제) 수와 전체 문제 수입니다. reasoning effort medium, T=10, k=2.
- 다섯 라운드를 모두 통과한 문제 5개. 문제 단위 붓스트랩 95% 구간 37.0~49.3%.
- 우연 기준(같은 길이로 파이프 타일을 무작위로 눌렀을 때 직전 규칙을 지킬 확률): 16.7%.
