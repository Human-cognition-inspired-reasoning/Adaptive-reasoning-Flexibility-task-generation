## claude-sonnet-5의 특성

보속은 세 모델 중 중간(0.084)이나, 실패 중 벽 통과 비중이 0.24로 다른 두 모델의 0.03–0.06보다 4배에서 8배 높다. 적응 성공률도 0.726로 세 모델 중 가장 낮고 미도달 전환이 192/700개다
(gpt-6.1-sol 적응 성공률 0.989, 벽 통과 0.06, claude-opus-5-5 적응 성공률 0.999, 벽 통과 0.03).
규칙 적응 능력(전환 뒤 직전 규칙을 다시 내지 않음)과 공간 이동의 정확성(벽을 넘지 않는 경로)이 분리되어 나타난 사례다. 지속적 오류율은 앞의 것을,
적응 성공률과 실패 유형은 뒤의 것을 함께 반영하므로, 모델 비교에서 두 지표를 같이 보고해야 한다.

**규칙별 소요 시간(claude-sonnet-5, 피드백)**: 라운드당 시도가 VIA 12.1회, AV 8.3회, NB 6.9회이고 호출당 응답 시간이 VIA 74.5초, AV 61.7초, NB 52.2초다. 시도 수와 응답 시간이 모두 규칙에 따라
달라져 규칙 유형별 API time의 차이를 만들었다(`METRICS_TABLE.md`: VIA 4,086분, AV 2,284분, NB 1,557분).
